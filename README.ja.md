Photoshop(`.aco`)カラーパレットを**表示・混合・書き出し**するツールで、**ブラウザ内で**完全に動作します。インストール不要、登録不要、データのアップロードなし。

> すべてのデータはお使いの端末で**100%ローカルに**処理されます。

**🌐 多言語 UI（6言語）:** Tiếng Việt、English、中文 (简体)、한국어、日本語、Español — **⚙️ 設定**で切り替え。

---

## ✨ 機能

### 📁 ACOを表示
- `.aco`ファイルをドラッグ＆ドロップ（またはクリック）して開きます。
- **ACO v1 & v2**に対応し、**カラー名**とRGB / HSB / CMYK / Lab / グレースケール色空間を読み取ります。
- 各色は**インデックス番号**、名前、HEX、RGB、元の色空間を表示します。
- 名前/HEX/RGBで**検索**し、色相・明度・彩度・名前で**並べ替え**。
- **高度な検索** — `hue:0-60`、`sat:>50`、`light:40-80`で範囲フィルター、`similar:#FF0000`で近似色を検索。

### ✏️ パレットを編集（その場で）
- 色の**名前変更**(✏️)、**削除**(🗑)、**追加**、そして**.acoに保存**。
- 完全な**元に戻す / やり直し**（最大60ステップ）。
- スウォッチを**右クリック**してクイックメニュー（コピー / 詳細 / 名前変更 / 書き出し / 削除）。

### 📋 コピー
- スウォッチをクリックするとコード（**HEX / RGB / HSL** — 選択可）をコピー。
- **すべてコピー**: HEXリスト、CSS変数、SCSS、JSON、RGB、**Tailwind config**、**Styled Components**。

### 🎨 色の混合（単体で使用 — ACO不要）
- **カラーピッカー**で色を追加、またはこのタブで直接**ACOファイルを開く**。
- 選択グリッドで**混ぜたくない色をワンクリックで除外**。
- ファイルを再アップロードせずに**選択を再調整**。
- 比率は色数に応じて**自動均等**。スライダーで個別に調整。
- **混合履歴**は自動保存され、クリックで再コピーできます。

### 🎲 ランダムカラー（メンバーごと）
- 各「メンバー」に1〜100個のランダムカラーを生成。完全ランダム、または色系統（赤 / オレンジ / 黄 / 緑 / シアン / 青 / 紫 / ピンク）から選択、重複なしモードも可能。

### 🛠 デザインツール
2つのタブ — **🧩 作成**と**🔍 分析**に分かれています:
- **パレット生成** — 補色 / 類似 / トライアド / スプリット / テトラード。
- **グラデーション生成** — 線形 / 放射 / **円錐** CSSグラデーション、クリップボードへコピー。
- **画像 → パレット / スポイト** — 画像をクリックして色を取得、主要色を抽出し**そのまま.acoに書き出し**。
- **プリセット＆テンプレート** — 内蔵のMaterial Design、Tailwind、ブランドカラー、パステル、アーストーン。
- **コントラストチェッカー** — AA/AAAバッジ付きWCAGコントラスト比。
- **アクセシビリティ監査** — 白/黒テキストに対してAAを満たすパレットの割合。
- **パレット統計** — 平均彩度/明度と色相分布チャート。
- **色覚異常プレビュー** — 第1色覚 / 第2色覚 / 第3色覚 / グレースケール。
- **カラー詳細パネル** — HEX / RGB / HSL / HSV / CMYK / Lab、輝度、コントラスト。
- **重複検出**と**近似色検索**。

### 📦 バッチ処理
- **複数の.acoファイル**を一度に開き、1つのパレットに**統合**（任意で重複除去）または**統合した.acoを書き出し**。

### 🔗 パレットを共有
- 現在のパレットをエンコードした**共有リンク**(`?palette=...`)を生成 — リンクを開いた誰もが同じ色を見られ、サーバー不要。

### 📐 グラデーション (.grd)
- Photoshop **グラデーションファイル**(`.grd`, **v3 & v5**) — ソリッドおよびノイズグラデーションを開きます。
- 各グラデーションを**プレビュー**し、カラーストップ、不透明度ストップ、中間点、滑らかさ、ノイズパラメータ（シード、粗さ、最小/最大）を**編集**。
- グラデーションとストップを**追加 / 削除**し、**`.grd`に保存**。
- グラデーションを**CSS `linear-gradient`** または**SVG**で書き出し、色を**`.aco`に抽出**またはビューアへ直接送信。

### ⬇ 書き出し
- レイアウト、サイズ、ラベル、背景（透明を含む）オプション付きの**PNG / SVG / CSS / JSON / TXT**。
- 選択した色の**ACO書き出し**（v2、カラー名付き）。

### 🌙 UI — グラスモーフィズム
- **グラスモーフィズム**デザイン: すりガラスパネル、ソフトなブラー、アンビエントライト — macOS/iOSのように洗練。
- **ダーク / ライト / 自動**テーマ（デフォルトはシステム追従）。
- **6言語**: Tiếng Việt、English、中文 (简体)、한국어、日本語、Español — **⚙️ 設定**で切り替え可能。
- 滑らかなアニメーションとモバイルファーストのレイアウト（ボトムナビ、ボトムシート、大きなタッチターゲット）。

### ⚙️ 設定
- **外観** — ライト、ダークまたは自動テーマ。
- **アクセントカラー** — UI全体（ロゴ、タブ、ボタン、グロー）を再配色。
- **言語**と**フォントサイズ**（小 / 中 / 大）。
- **サウンド効果** — クリック、コピー、通知時に控えめな音を再生（オン/オフ）。
- **モーション効果**オン/オフ、**保存データの消去**、**このアプリについて**。

### 📲 アプリとしてインストール (PWA)
- **デスクトップ（Windows/macOS/Linux）** と**モバイル（Android/iOS）** にインストール可能。
- 独自アイコン、スタンドアロンウィンドウで開き、**オフライン**で動作。

### 🖥 デスクトップ版（Windows）
- Electronで**ネイティブWindowsデスクトップアプリ**としてパッケージ — `electron-app/`フォルダ参照。
- **Windows**向けインストーラーをビルド: `.exe`（インストーラー＋ポータブル）。
- アプリのロゴは現代のアプリのように**角丸**です。

## 🚀 使い方

### デスクトップ / モバイル
任意のブラウザで`index.html`を開く（ダブルクリック）、またはデプロイ済みURLにアクセス。

### クイックフロー
1. **📁 ACOを表示**タブを開く → `.aco`ファイルをドラッグ＆ドロップ。
2. 色をクリックしてコピー、または複数の色を選択して書き出し。
3. **🎨 色の混合**タブを開く → 色を追加 → 混合結果を即座に確認。
4. **⬇ 画像＆データを書き出し**をクリックしてパレットをダウンロード。
5. **📐 グラデーション**タブを開く → `.grd`ファイルをドロップして表示・編集。
6. **⚙️ 設定**を開いてテーマ、アクセントカラー、言語、フォントサイズを切り替え。

## 📲 アプリとしてインストール (PWA)

アプリをデプロイすると（HTTPS経由）、実際のアプリとしてインストールできます:

| プラットフォーム | 方法 |
|------------------|------|
| **デスクトップ**（Chrome/Edge） | URLを開く → **📲**ボタンまたはアドレスバーのインストールアイコン → **インストール** |
| **Android**（Chrome） | URLを開く → **⋮**メニュー → **ホーム画面に追加** |
| **iPhone/iPad**（Safari） | URLを開く → **共有**ボタン → **ホーム画面に追加** |

> **重要:** PWAは**HTTPS**で配信する必要があります（GitHub Pages、Netlify、Vercelすべて対応）。`file://`を直接開いた場合はインストールできません。

## ❓ FAQ

**データはどこかにアップロードされますか？**
いいえ。すべてブラウザ内で実行され、ネットワークに何も送信されません。

**ファイルを開いても色が表示されません？**
有効な`.aco`ファイルか確認してください。一部のソフトウェアは非標準構造でACOを書き出します。

**色の混合はどのように機能しますか？**
アプリは比率（加重平均）で色を混ぜます — 絵の具を混ぜるようなものです。スライダーをドラッグして色を「重く」できます。

**ファイルの一部の色だけ混ぜるには？**
**色の混合**タブでACOを開き → 混ぜたくない色をクリックして解除 → **色を混合に追加**をクリック。
